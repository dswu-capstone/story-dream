# 캐릭터 감정 이미지

퀴즈/집중 유도 오버레이에 쓰이는 캐릭터 얼굴 이미지입니다.
Realtime이 질문을 만들 때 함께 출력한 감정(`happy` / `sad` / `angry` / `scared`)에 따라
아래 파일을 찾고, 파일이 없으면 `../duck.jpg`로 폴백합니다.

아직 감정별 그림이 준비되지 않았으므로 폴더는 비어 있습니다.
그림이 준비되면 이 이름 그대로 넣기만 하면 됩니다 (코드 수정 불필요):

- `happy.jpg` — 기쁜 얼굴
- `sad.jpg` — 슬픈 얼굴
- `angry.jpg` — 화난 얼굴
- `scared.jpg` — 겁먹은 얼굴
